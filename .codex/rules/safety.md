# Safety Rules

## 목적

비밀 값, 운영 데이터, 위험한 명령, 대규모 변경으로부터 레포와 서비스를 보호한다.

## 금지 사항

- 비밀 값 커밋 금지
- 운영 DB에 직접 영향을 주는 명령 실행 금지
- 사용자 승인 없는 `git reset --hard` 금지
- 사용자 승인 없는 강제 push 금지
- 실패 테스트 무단 삭제 금지
- 요청과 무관한 대량 포맷팅 금지
- 결제/보상/랭킹 산식 추측 변경 금지

## 승인 필요

- DB 스키마 변경
- 배포 파이프라인 변경
- 운영 환경 변수 변경
- 대량 데이터 보정 스크립트
- 결제, 보상, 랭킹 정책 변경

## 비밀 값

- `.env`, 토큰, API 키, DB 비밀번호를 문서나 코드에 직접 쓰지 않는다.
- 로그에 토큰, 결제 식별자, 개인정보가 노출되지 않도록 확인한다.
