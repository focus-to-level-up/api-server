# Skill: add-batch-job

## 목적

Batch 작업을 추가하거나 수정할 때 따르는 절차다.

## 사용 시점

- 랭킹 정산 작업 추가/수정
- 주간 보상 지급 작업 추가/수정
- 통계 집계 작업 추가/수정
- 만료 처리 또는 데이터 보정 작업 추가/수정

## 절차

1. 작업의 실행 주기와 기준 시각을 정의한다.
2. 대상 데이터 범위와 제외 조건을 정의한다.
3. 중복 실행 방지 전략을 정한다.
4. 실패 후 재실행 가능성을 검토한다.
5. 트랜잭션 경계와 chunk 처리 필요 여부를 확인한다.
6. 운영 로그와 결과 확인 방법을 정한다.
7. 필요하면 `integrity-reviewer`와 `devops-reviewer` 관점으로 검토한다.
8. 변경 사항과 검증 결과를 `docs/harness/PROGRESS.md`에 기록한다.

## 완료 기준

- 중복 실행되어도 결과가 깨지지 않는다.
- 재실행 기준이 설명되어 있다.
- 운영자가 결과를 확인할 수 있다.
