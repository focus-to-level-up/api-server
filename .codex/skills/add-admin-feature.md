# Skill: add-admin-feature

## 목적

운영자/CS 기능을 추가하거나 수정할 때 따르는 절차다.

## 사용 시점

- 유저 조회 기능 추가
- 재화/패키지 지급 기능 추가
- 신고, 랭킹 경고, 길드 수정 기능 변경
- 관리자 권한이 필요한 기능 변경

## 절차

1. 운영자가 해결하려는 CS 또는 운영 시나리오를 정의한다.
2. 대상 데이터와 변경 가능한 필드를 확인한다.
3. 관리자 권한 요구사항을 확인한다.
4. 수동 지급/수정의 중복 처리와 오조작 가능성을 검토한다.
5. 추적 가능성이 필요한지 확인한다.
6. 필요하면 `security-reviewer`와 `integrity-reviewer` 관점으로 검토한다.
7. 테스트 또는 수동 검증 시나리오를 작성한다.
8. 변경 사항과 검증 결과를 `docs/harness/PROGRESS.md`에 기록한다.

## 완료 기준

- 관리자 권한과 실패 케이스가 명확하다.
- 운영자가 실제 CS 상황에서 사용할 수 있다.
- 수동 변경의 위험이 검토되어 있다.
